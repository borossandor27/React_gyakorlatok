# Viccek kártyákon

A viccek a `https://merlinvizsga.hu/api/vicc/` végpontról töltődnek be az `axios` és a `useEffect` segítségével.

## Indítás

```bash
npm install
```

```bash
npm run dev
```

A projekt korábban Create React Appre épült; mivel azt már nem tartják karban, [Vite](https://vite.dev/)-re állt át.
